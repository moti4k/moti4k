# Classical ML: valuation, risk and recommendations

## Property valuation at QLAN

I worked on tabular ML for identifying undervalued apartments in Dubai. The work included deep feature engineering, feature selection and comparisons between gradient boosting, linear models and other tabular/graph-based approaches.

The purpose was to turn listing data into a useful property-screening workflow, connecting model predictions with real purchase and resale decisions. The underlying client data and implementation are private.

## Contractor default risk — AI Challenge 2024

With Artyom Goncharov, I developed the **first-place team solution in the Development track**: predicting contractor default over a six-month horizon and explaining predictions in a web interface.

The public implementation includes financial and temporal features, graph-derived features, feature selection, Random Forest/CatBoost ensembles, grouped validation and SHAP explanations.

**[Code, notebooks and technical report](https://github.com/moti4k/aiijc_2024_samolet_scoring)**
